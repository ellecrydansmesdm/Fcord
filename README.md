## About

FCord extends the official Discord desktop and web clients with an extensive plugin catalogue, custom CSS styling, custom profile personalization, multi-account isolation, integrated media playback, and cloud synchronization. Every feature can be independently toggled and configured through the client settings.

FCord is developed and maintained by Fahd ([@ellecrydansmesdm](https://github.com/ellecrydansmesdm)).

## Features

- **Extensive Plugin Catalogue**: Configure chat enhancements, notification filters, server utilities, voice tools, privacy controls, and shortcuts.
- **Themes and Profiles**: Apply QuickCSS, custom local stylesheets, theme links, and per-account profile cosmetics (custom badges, effects, bios, and banners).
- **Account Isolation & DPAPI Vault**: Switch accounts seamlessly via the Discord UI. Account credentials and tokens are secured locally via Windows DPAPI and Electron `safeStorage`.
- **Integrated Voice & Media Tools**: In-call SoundPad with peer voice transmission, audio ducking prevention, microphone passthrough, and SoundCloud streaming.
- **Backup & Cloud Synchronization**: Export configurations locally or synchronize settings, custom profiles, and QuickCSS via optional backend sync.
- **In-Client Atomic Updates**: Update published releases directly from the client notification banner with automatic directory swapping and rollback protection.

## Installation

FCord supports Discord **Stable**, **PTB**, and **Canary** on desktop, as well as **Discord Web**.

### 🪟 Windows (x64 & ARM64)

1. Launch your preferred Discord desktop channel (**Stable**, **PTB**, or **Canary**) at least once.
2. Download [**FCord-Installer-Online-win-x64.exe**](https://github.com/ellecrydansmesdm/Fcord/releases/latest/download/FCord-Installer-Online-win-x64.exe) *(or the offline package [**FCord-Installer-Offline-win-x64.exe**](https://github.com/ellecrydansmesdm/Fcord/releases/latest/download/FCord-Installer-Offline-win-x64.exe))*.
3. Close Discord completely (ensure no background processes remain in the system tray).
4. Run the installer:
   - **GUI Mode**: Double-click the installer, select your Discord channel, and click **Install**.
   - **Silent / CLI Mode**: Execute `FCord-Installer-Online-win-x64.exe /S` from terminal for automated installation.
   - *If SmartScreen appears: click **More info** → **Run anyway**.*
   - *If Smart App Control (SAC on Windows 11) blocks execution: right-click the `.exe` → **Properties** → check **Unblock** → **Apply**.*
5. Launch Discord — FCord settings and plugins will appear under **User Settings → FCord**.

### 🍎 macOS (Apple Silicon & Intel)

1. Ensure Discord has been opened at least once on your Mac.
2. Download the package for your hardware:
   - **Universal (Any Mac)**: [**FCord-Installer-macOS-universal.dmg**](https://github.com/ellecrydansmesdm/Fcord/releases/latest/download/FCord-Installer-macOS-universal.dmg) *(or [`.zip`](https://github.com/ellecrydansmesdm/Fcord/releases/latest/download/FCord-Installer-macOS-universal.zip))*
   - **Apple Silicon (M1 / M2 / M3 / M4)**: [**FCord-Installer-macOS-arm64.dmg**](https://github.com/ellecrydansmesdm/Fcord/releases/latest/download/FCord-Installer-macOS-arm64.dmg)
   - **Intel (x64)**: [**FCord-Installer-macOS-x64.dmg**](https://github.com/ellecrydansmesdm/Fcord/releases/latest/download/FCord-Installer-macOS-x64.dmg)
3. Open the `.dmg` file and drag `FCord-Installer.app` to your Applications folder.
4. **Gatekeeper Bypass (Unsigned App)**:
   - **GUI Method**: **Right-click** `FCord-Installer.app` → select **Open** → confirm by clicking **Open**.
   - **Terminal Command**: Clear the Gatekeeper quarantine attribute by running:
     ```bash
     xattr -cr /Applications/FCord*.app
     ```
5. Select your Discord channel and click **Install**, then restart Discord.

### 🐧 Linux (x64 AppImage & tar.gz)

The Linux installer automatically detects Discord installations across native directories (`/usr/share/discord`, `/opt/discord`), Flatpak (`/var/lib/flatpak`, `~/.local/share/flatpak`), and Snap (`/snap/discord`).

#### Option A: Standalone AppImage (Recommended)
1. Download [**FCord-Installer-Linux-x64.AppImage**](https://github.com/ellecrydansmesdm/Fcord/releases/latest/download/FCord-Installer-Linux-x64.AppImage).
2. Make the AppImage executable:
   ```bash
   chmod +x FCord-Installer-Linux-x64.AppImage
   ```
3. Run the installer:
   ```bash
   ./FCord-Installer-Linux-x64.AppImage
   ```
4. Select your Discord installation and click **Install**.

#### Option B: Standalone Tarball (.tar.gz)
1. Download [**FCord-Installer-Linux-x64.tar.gz**](https://github.com/ellecrydansmesdm/Fcord/releases/latest/download/FCord-Installer-Linux-x64.tar.gz).
2. Extract the archive and execute the installer:
   ```bash
   tar -xzf FCord-Installer-Linux-x64.tar.gz
   cd FCord-Installer-Linux-x64
   chmod +x fcord-installer
   ./fcord-installer
   ```

### 🌐 Discord Web (Browser Extensions & UserScript)

1. **Chromium (Chrome, Edge, Brave, Opera)**:
   - Download [**extension-chrome.zip**](https://github.com/ellecrydansmesdm/Fcord/releases/latest/download/extension-chrome.zip) and extract it to a folder.
   - Open your browser's extension manager (`chrome://extensions` or `edge://extensions`).
   - Enable **Developer mode** in the top right.
   - Click **Load unpacked** and select the extracted folder.
   - Navigate to `https://discord.com/app`.
2. **Mozilla Firefox**:
   - Download [**extension-firefox.zip**](https://github.com/ellecrydansmesdm/Fcord/releases/latest/download/extension-firefox.zip) and extract it.
   - Open `about:debugging#/runtime/this-firefox`.
   - Click **Load Temporary Add-on...** and select `manifest.json` from the extracted folder.
   - Navigate to `https://discord.com/app`.
3. **UserScript (Violentmonkey / Tampermonkey)**:
   - Install the Violentmonkey or Tampermonkey extension in your browser.
   - Click [**FCord.user.js**](https://github.com/ellecrydansmesdm/Fcord/releases/latest/download/FCord.user.js) to prompt the extension to install the userscript.
   - Navigate to `https://discord.com/app`.

## Updating and Uninstalling

### Seamless In-Client Updates
FCord includes an integrated atomic updater (`http.ts`). When an update is published:
1. Discord displays a top notification banner alerting you that a new version is available.
2. Click **Update Now** — FCord downloads the verified runtime payload (`fcord-dist.zip`), validates its cryptographic SHA-256 hash against `checksums.txt`, and swaps the application directory atomically (`atomicSwapDirectories`).
3. Restart Discord to load the updated release. All settings, custom plugins, themes, and tokens are preserved.
> **Note**: Existing users do **not** need to re-download the installer for routine updates!

### Re-patching after Discord Client Updates
When Discord releases a core client update, it may overwrite its application directory. Simply run the latest `FCord-Installer` again and click **Install** to re-inject FCord.

### Clean Uninstall
To completely remove FCord:
1. Run `FCord-Installer` on your OS.
2. Select your Discord channel and click **Uninstall**.
3. The installer removes the FCord loader shim and cleanly restores Discord's original application archive.

## Security and Privacy

FCord is built with strict privacy and security standards:

- **Hardware-Backed Encryption**: Tokens, credentials, and sensitive configurations are secured locally using Windows DPAPI and Electron `safeStorage`. Plaintext credentials never touch disk storage.
- **Process & Storage Isolation**: Multi-account sessions operate with separated local cache boundaries, preventing token leakage between accounts or client channels (Stable, PTB, Canary).
- **Anti-Log & Telemetry Control**: Built-in options to block tracking endpoints, mute unwanted typing indicators, and sanitize sent messages.
- **Self-Contained Payloads**: Installer and updater payloads execute without downloading unverified third-party scripts at runtime.
