The repository may be opened to the public in the future; no date has been announced.

3. SOURCE CODE OF EACH RELEASE
The private development repository and the source code of releases are two different things. The development repository (its history, branches and work in progress) is not published. The GPL applies to what is distributed: for each FCord release, the corresponding source code of its runtime is provided on request to anyone who has that release, for at least three years after it was published. To request it, open an issue titled "Source code request" at https://github.com/ellecrydansmesdm/Fcord/issues and give the version number. You receive an archive of that release's source code with build instructions, without the development history or private branches.
